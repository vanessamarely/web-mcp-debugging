# Web MCP & Debugging

Este repositorio contiene una presentación en formato web sobre **Web MCP y debugging moderno**.

## Contenido

- `index.html`: slide deck completo (22 diapositivas) con navegación integrada.
- Temas principales:
  - Problemas actuales de debugging asistido por IA.
  - Qué es Model Context Protocol (MCP).
  - Chrome DevTools MCP y su flujo de trabajo.
  - Seguridad, economía del contexto y futuro de la web agent-ready.

## Cómo ver la presentación

1. Abre el archivo `vanessamarely/web-mcp-debugging/index.html` en tu navegador de manera local o usa https://vanessamarely.github.io/web-mcp-debugging/.
2. Navega con:
   - **Espacio**, **Enter** o **→** para avanzar.
   - **←** para retroceder.
   - También puedes usar los botones inferiores o gestos táctiles (swipe).
